# 硬件改版设计说明（电源审查 + 新板引脚表）

> 2026-11-18。用户决定换到 STM32F407VET6、自己画 PCB。
> 现有 1.0 板（教学板（STM32F103RCT6））的原理图**就是**要参考的那一份，
> 所以先把它的电源设计逐项审一遍，再给新板的方案和引脚表。

---

## 一、现有 1.0 板电源设计审查

参考图：DC005 输入 7.4–12V → 1N4007 防反接 → 开关 → LM2596S-5.0（3A）→ 5V，
5V 再分三路 LM1117MPX-3.3（各 800mA）分别给 MCU、外部 3.3V 模块、WiFi。

### 1.1 结论先说

**能用，但有三处会限制后续 2.0，两处画板时必须注意。** 逐条如下。

| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| 1 | LM2596 效率低、静态电流大 | 中 | 150kHz 非同步，12V→5V 满载效率约 75–80%，空载静态约 5mA。整机常年通电时板子会温，电池包里也费电 |
| 2 | 三路 1117 的耗散被低估 | 中 | 每路 (5−3.3)×I：MCU 0.14W、外部 0.34W、WiFi 0.51W。SOT-223 不铺铜时 WiFi 那路会烫到限流 |
| 3 | WiFi 轨储能不足 | **高** | 3.3V 输出只有 10µF+100nF，ESP8266 发射 300mA 脉冲会打出几百 mV 凹陷，表现为随机断连/复位 |
| 4 | 无保险丝、无 TVS | **高** | 图里的 SS-12D10L5 是**开关不是保险**。外接 12V 电磁锁 1A 短路时没有任何保护，MOS/走线会直接烧 |
| 5 | 防反接用 1N4007 | 中 | 0.7–0.9V 压降，1.3A 时白烧约 1W。换 SS34（0.4V）或 P-MOS 理想二极管 |
| 6 | 1117 输出电容选型 | 低 | LM1117 老手册要求输出用 10µF **钽**（对 ESR 有要求），纯低 ESR 陶瓷在个别批次上会振荡。稳妥做法：陶瓷 + 串 0.1–0.5Ω，或直接用电解/钽 |
| 7 | 三颗指示 LED 占地方 | 低 | 各 1.5mA 无所谓，但画板占位。建议只留 5V 一颗，3.3V 三路用测试点代替 |
| 8 | 电感的饱和电流没标 | 中 | 33µH 对 5V/3A 是对的，但必须选 Isat ≥ 4.5A 的型号，饱和了 LM2596 会炸开关管 |

### 1.2 画板时必须注意的两处

| 项 | 要求 |
|---|---|
| LM2596 的 EP（6 脚背部散热片） | 必须焊到大面积 GND 铜上，并且打过孔阵列。不焊等于没有散热，3A 标称打折到 1A |
| 开关环路面积 | C1（680µF 输入电容）— VIN/GND — SS54 — L1 围成的环路要尽量小。这是整板最主要的辐射源，环路大了会干扰指纹串口和 WiFi |

### 1.3 一处需要确认的（图上看不清）

`ON/OFF`（5 脚）最初看着像悬空，但第二张图显示已接地 —— **必须低电平使能，悬空会不启动**。
如果最终图里仍悬空，加 10kΩ 下拉到 GND。

## 二、新板电源方案

### 2.1 总体拓扑

```
DC 12V 输入
  │
  ├─ F1 自恢复保险丝 2A
  ├─ D1 SS34（防反接）
  ├─ TVS SMBJ15A（吸收感性反压）
  │
  ├──> 12V 轨 ──> 继电器 COM ──> 电磁锁（1A，仅开锁 3 秒）
  │                    │
  │                    └─ 锁线圈两端并 1N4007/SS34（续流，装在板上靠近接口）
  │
  └──> LM2596S-5.0（或换同步降压）──> 5V 轨
           │
           ├──> 继电器线圈 5V（35mA）
           ├──> 1117-3.3 #1 ──> MCU（80mA）
           ├──> 1117-3.3 #2 ──> 指纹 + OLED + W25Q（200mA）
           └──> 1117-3.3 #3 ──> ESP8266（300mA 峰值，就近加 470µF）
```

### 2.2 建议替换的器件

| 位置 | 现有 | 建议 | 理由 |
|---|---|---|---|
| 主降压 | LM2596S-5.0 | **MP1584EN / SY8205 / TPS5450**（模块或芯片） | 同步整流，效率 90%+，静态电流小，发热少一半 |
| 防反接 | 1N4007 | **SS34** 或 P-MOS（AO3401） | 压降从 0.8V 降到 0.4V / 0.05V |
| 保护 | 无 | 2A 自恢复保险 + SMBJ15A | 锁短路时不烧板 |
| WiFi 储能 | 10µF | **+470µF 电解 + 100nF** | 抑制发射脉冲压降 |
| 电感 | 33µH | 33µH / **Isat ≥ 4.5A** | 饱和电流不够会炸管 |

如果不想换降压芯片，LM2596 继续用也行 —— 只是效率低、板子热，功能上没问题。

## 三、F407VET6 最小系统（漏了会不启动）

| 引脚 | 接法 | 漏了会怎样 |
|---|---|---|
| **VCAP_1 / VCAP_2** | 各 2.2µF 到 GND | 内核调压器不稳，**跑飞或不启动**，F4 最经典的坑 |
| VDD（多脚） | 每脚就近 100nF | 高频不稳，随机死机 |
| VDDA | 磁珠 + 1µF + 10nF | 时钟抖动、ADC 不准 |
| VSSA | 单独接到 GND | 同上 |
| VBAT | 接 3.3V 或 100nF 到地 | 不接也能跑，RTC 丢 |
| BOOT0 | 10kΩ 下拉 GND | 上电进不了用户程序 |
| NRST | 100nF 到地 + 10kΩ 上拉 | 复位不可靠 |
| PH0 / PH1 | 8MHz 晶振 + 2×20pF | 不用 HSE 就只能跑内部 RC，主频上不去 |
| PA13 / PA14 | SWD 排针（3.3V/GND/SWDIO/SWCLK） | 无法下载调试 |
| PDR_ON（部分封装） | 接 3.3V | 不接可能上电不稳 |

## 四、新板引脚分配表

原则：**串口/SPI/I2C 全部保持原位**，让 `as608.c`、`esp8266.c`、`w25q.c`、`app_oled.c` 一行不用改；
只有键盘和 LED 换脚。

| 功能 | F407VET6 引脚 | 与 1.0 板对比 | 代码改动 |
|---|---|---|---|
| 调试串口 USART1 | PA9 TX / PA10 RX | 相同 | 无 |
| ESP8266 USART3 | PB10 TX / PB11 RX | 相同 | 无 |
| AS608 UART4 | PC10 TX / PC11 RX | 相同 | 无 |
| OLED I2C1 | PB6 SCL / PB7 SDA | 相同 | 无 |
| W25Q SPI2 | PB13 SCK / PB14 MISO / PB15 MOSI / PB12 CS | 相同 | 无 |
| 键盘 行 R1–R4 | PD0 / PD1 / PD2 / PD3 | 原 PB0/PB1/PB3/PA1 | 只改数组 |
| 键盘 列 C1–C4 | PD4 / PD5 / PD6 / PD7 | 原 PB4/PB9/PA2/PB5 | 只改数组 |
| 锁体（继电器 IN） | PC0 | 相同 | 无 |
| 状态 LED | PE0 | 原 PA15 | 改一行 |
| SWD | PA13 SWDIO / PA14 SWCLK | — | — |
| 晶振 | PH0 / PH1（8MHz） | — | — |

留出来的扩展口：PE1–PE15、PC1–PC13，够以后加门磁、蜂鸣器、RTC、第二路锁。

**注意**：新方案把键盘从 PA/PB 挪到 PD，好处是**再也不用 `__HAL_AFIO_REMAP_SWJ_NOJTAG()`**，
PB3/PB4 留给调试口，少一个坑。

## 六、画板顺序建议

1. 先画**电源区**（12V→5V→3.3V），单独打样验证电压对不对，再往下画
2. MCU 区：VCAP、BOOT0、NRST、晶振、SWD 先画，再分串口/SPI/I2C
3. 接口区：串口、SPI、I2C、键盘、继电器输出都上排针，方便飞线调试
4. 第一次打样一定留**测试点**：12V / 5V / 3.3V×3 / GND
5. 板子回来先测电压，再焊 MCU —— 避免焊完才发现电源不对
